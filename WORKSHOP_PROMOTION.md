## What You'll Learn

### Core Concepts (Explained + Coded)
- **Agent State** — How data flows through the system without getting lost
- **Tool Calling** — How Claude decides which function to invoke
- **The ReAct Loop** — Reason → Act → Observe → Repeat (the engine of all agents)
- **LangGraph State Machines** — Nodes, edges, and conditional routers
- **Termination Conditions** — How agents know when to stop
- **Anthropic Integration** — Binding tools to Claude and streaming responses

### Hands-On Skills You'll Practice
1. **Run a live agent** — Ask infrastructure questions; watch it autonomously research and synthesize
2. **Trace code execution** — Follow a question through the state machine step by step
3. **Modify the knowledge base** — Add your own best practices; watch the agent use them
4. **Change agent behavior** — Modify tools, swap models, observe the impact
5. **Debug agent reasoning** — Read console output to understand why the agent made each decision

## FAQs

**Q: I'm new to AI. Can I still attend?**  
A: Yes! This workshop assumes zero AI background. We start from "what is a tool?" and build up.

**Q: Do I need to know LangGraph already?**  
A: No. We explain LangGraph live as we read the code. It's not complicated once you see it.

**Q: Will this teach me everything about agents?**  
A: No. This is a 3-hour introduction. It gives you the mental model and core patterns. You'll extend it for months afterward.

**Q: Can I use these agents in production?**  
A: This is a learning demo, not production-ready. But the patterns scale directly. We'll discuss production considerations in the Q&A.

**Q: What if I can't attend live?**  
A: Recordings will be provided (if available). The code and detailed agenda are on GitHub, so you can follow along asynchronously.

**Q: Can I use an open-source LLM instead of Claude?**  
A: Yes, once you understand the pattern. This workshop uses Claude for simplicity, but the ReAct loop works with any LLM (LLaMA, Mistral, etc.).

**Q: Is this a sales pitch for Anthropic?**  
A: No. We use Claude because it's a well-documented, capable model. The patterns you learn apply to any LLM framework.
